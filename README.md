# Machine Learning Basics

A comprehensive learning repository for mastering machine learning fundamentals, covering data processing, supervised learning, unsupervised learning, evaluation metrics, and model optimization.

## 📚 Repository Structure

### 1. Data Processing (`1_Data_Processing/`)
Fundamentals of preparing data for machine learning models:
- **Handling Missing Values** - Techniques for dealing with incomplete datasets
- **Encoding Data** - Converting categorical data to numerical format
- **Data Scaling** - Normalization and standardization of features
- **Data Splitting** - Train-test split and cross-validation strategies

### 2. Supervised Learning (`2_Supervised_Learning/`)
Algorithms for learning from labeled data:
- **Linear Regression** - Predicting continuous values
- **Logistic Regression** - Binary and multi-class classification
- **K-Nearest Neighbors (KNN)** - Instance-based learning
- **Decision Tree** - Tree-based classification and regression
- Comprehensive notes covering supervised learning concepts

### 3. Evaluation Metrics (`3_Evaluation_Metrics/`)
Methods to assess model performance:
- **Regression Metrics** - MSE, RMSE, MAE, R²
- **Classification Metrics** - Accuracy, Precision, Recall, F1-Score, ROC-AUC
- Detailed evaluation metrics notes

### 4. Projects

#### Project 1: Linear Regression (`4_Project1(Linear_Regression)/`)
Practical application of linear regression techniques

#### Project 2: Linear Regression (`5_Project2(Linear_Regression)/`)
Advanced linear regression implementation

#### Project 3: Logistic Regression (`7_Project3(Logistic_Regression)/`)
Classification project using logistic regression

### 5. Unsupervised Learning (`6_Unsupervised_Learning/`)
Algorithms for learning from unlabeled data:
- **K-Means Clustering** - Partitioning data into clusters
- **Principal Component Analysis (PCA)** - Dimensionality reduction
- Comprehensive unsupervised learning notes

### 6. Model Optimization & Generalization (`8_Model_Optimization_Generalization/`)
Techniques for improving model performance:
- **Regularization** - L1, L2 to prevent overfitting
- **Hyperparameter Tuning** - Optimizing model parameters
- **Cross Validation** - Robust model evaluation strategies

## 📊 Datasets

- **Study_Hours.csv** - Study hours data for regression analysis
- **Student_Pass_Fail_Dataset.csv** - Student performance classification dataset
- **Students_Performance_Dataset.csv** - Comprehensive student performance data
- **Sample_Data.csv** - Sample dataset for practice

## 🎯 Learning Path

1. Start with **Data Processing** to understand data preparation
2. Move to **Supervised Learning** for core algorithms
3. Learn **Evaluation Metrics** to assess model performance
4. Apply knowledge through **Projects**
5. Explore **Unsupervised Learning** for unlabeled data
6. Master **Model Optimization** for production-ready models
